# Changelog

## 0.1.0 — 2026-11-22

The first release.

**Recording**

- Whole-screen capture with the pointer, on the display you choose
- A camera bubble that floats above everything: drag it anywhere, it snaps to corners, scroll to resize
- Microphone with a live level meter; computer sound on Windows and macOS 14.2+
- Screen + camera, screen only, or camera only
- No time limit: video goes to disk every second, so long recordings use no more memory than short ones
- Pause and resume, countdown, 720p to 4K, 15 / 30 / 60 fps

**For how-to videos**

- Chapter markers, saved into the video and copyable as YouTube timestamps
- Cursor highlight and draw-on-screen
- Global shortcuts for everything; the window hides itself while you record

**Afterwards**

- Saved automatically as MP4 (H.264 + AAC)
- A library with thumbnails, rename, trim and GIF export

**Safety nets**

- Recordings interrupted by a crash are offered for recovery on the next start
- A full disk stops and saves the recording instead of corrupting it

**Installing**

- Windows: one line in PowerShell, no administrator rights
- macOS, Linux and Windows: one `npm install -g` command
